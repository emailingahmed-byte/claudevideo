# RSIFF Logo Files — Needed

Place the following files in this directory:

- `rsiff-horizontal-black.svg` — horizontal lockup, black (Arabic top, "RED SEA INTERNATIONAL FILM FESTIVAL" below)
- `rsiff-vertical-black.svg` — vertical stacked lockup, black
- `rsiff-horizontal-white.svg` — horizontal lockup, white (for use over photography / dark color fields)
- `rsiff-vertical-white.svg` — vertical stacked lockup, white

SVG is strongly preferred — the logo uses a custom wordmark (distinctive wide "R" with flared horizontal bars) that must scale cleanly in video. PNG at 2000px+ width is an acceptable fallback.

These files are referenced from `brands/red-sea/brand.json` → `assets.*`.
