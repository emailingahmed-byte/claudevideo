# RSIFF Fonts — Needed

The brand specifies three licensed typefaces. Drop the font files here:

| Role | Font | Foundry / Source | Files expected |
|------|------|------------------|----------------|
| English (all) | **Nohemi** | Pangram Pangram Foundry | `Nohemi-Light.otf`, `Nohemi-Regular.otf`, `Nohemi-Medium.otf`, `Nohemi-Bold.otf`, `Nohemi-ExtraBold.otf`, `Nohemi-Black.otf` |
| Arabic display | **Panorama** | — | `Panorama-Bold.otf` (or equivalent) |
| Arabic body | **Rawasi** | — | `Rawasi-Regular.otf` (or equivalent) |

`.woff2` is also fine and renders faster in Remotion Studio.

If these fonts are not available, the project falls back to:
- **Archivo** / **Archivo Black** for English (open source, Google Fonts)
- **IBM Plex Sans Arabic** for Arabic display and body (open source, Google Fonts)

Fallbacks are close but not exact — the custom RSIFF wordmark in the logo files still carries the brand.
